## 👋 关于我 · About

我喜欢钻研那些“本来应该更简单”的事情：媒体自动化、自托管服务、Apple 生态和代理工具。平时维护 MoviePilot 相关项目，也会把真实使用中的问题整理成脚本、插件、文档和可复用的工具。

I enjoy making complicated workflows feel simple, stable and pleasant. My main interests are media automation, self-hosting, the Apple ecosystem and proxy tooling. Most of my projects start from a real daily-use problem and grow into something reusable.

## ✨ 我的偏好 · Principles

- **先解决真实问题 / Start from real problems**：日常使用中遇到的痛点，才是最好的需求来源。
- **稳定比堆功能重要 / Stability over feature count**：少一点魔法，多一点可观察、可回滚和可维护。
- **体验也是功能 / UX is a feature**：好工具应该清晰、顺手，并且让人愿意长期使用。
- **把改进留给社区 / Share improvements**：能抽象成通用能力的，就尽量沉淀为公开项目。
