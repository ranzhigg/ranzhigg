## `01` 关于我

我喜欢研究技术。遇到感兴趣的问题，会从“能用”继续追到“为什么能用”，再想办法让它更稳定、更自然。

闲暇时主要折腾家庭媒体自动化，让下载、整理、入库和播放顺畅衔接。我也是 Apple 生态爱好者，喜欢软硬件配合得恰到好处的体验。
